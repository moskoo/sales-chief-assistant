# 可直接使用的输出模板

按任务选择并删减。方括号是实际填写位置；未知内容保留为“待核实”，不自动补造。内部分析与对外文案分开。

## 1. 轻量业务配置

只填当前任务需要的项目，可在后续对话补充：

```text
销售模式与渠道：[ToB / ToC、直销 / 渠道 / 私域等]
产品与目标场景：[卖什么、解决谁的什么问题]
产品事实与证明：[现有能力、限制、资料、可公开案例]
定价与权限：[币种、含税口径、已批准报价、让步与承诺边界]
目标客户：[行业、规模、角色、适配与排除条件]
流程与目标：[实际商机阶段、签约 / 收入 / 回款指标、目标期间]
工具与数据：[可用系统、实际字段、数据截止日、时区]
当前任务：[这次需要作出的决定或交付的成品]
```

不要声称这些配置会跨聊天永久保存；只有环境明确支持且用户授权时才使用相应存储能力。

## 4. 外联与跟进草稿

首次接触：

> [称呼]，我是[身份]。看到[可核验的相关背景]，想了解你们在[具体流程]上是否也有[待验证问题]。我们能提供[有依据的帮助]。如果这是您负责的方向，是否方便[一个低负担的下一步]？

已沟通后的跟进：

> [称呼]，上次您提到[已确认问题]。我整理了[本次新增材料或答案]，重点回应[顾虑]。[一句准确结论与必要边界]。关于[下一步]，我们[已约定事项 / 建议的动作]，您看是否合适？

根据客户渠道习惯调整长度；客户未说过的话不能放进“您提到”。清晰拒绝或要求停止后不再设计持续追发序列。

- “请使用 sales-chief-assistant 技能，读这段客户聊天，区分事实和推断，判断真正顾虑，给一条适合微信发送的回复。”

- “请使用 sales-chief-assistant 技能，分析这份 CRM 快照，列本周优先商机、数据缺口和预测限制。”
- “请使用 sales-chief-assistant 技能，扮演客户采购负责人，陪我练习价格异议，一轮一句，结束后按实际表现复盘。”
- “请使用 sales-chief-assistant 技能，把这批客户按现有购买与沟通记录分层，设计可维护的标签和本周跟进动作。”
- “请使用 sales-chief-assistant 技能，为这项服务设计一个可测试交付包，写清输入、验收、修改范围和报价条件。”
- “请使用 sales-chief-assistant 技能，把这些外贸询盘分出待补信息和需要人工接手的部分，起草回复，不直接发送。”
