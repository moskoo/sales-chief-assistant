# 收入、价值与数据口径

用于 ROI / TCO、CRM 数据分析、漏斗和销售预测。先统一口径，再计算；输入不足时给缺口和情景，不补造数据。

## 1. 数据准备

确认统计截止时间与时区、观察区间、团队与客户范围、币种、含税与否，以及指标对应签约、收入确认还是回款。区分订单总额、合同总额（TCV）、年化经常性收入（ARR）、新增收入和续约收入。

检查商机 ID 去重、阶段映射、金额单位、失效记录、缺失值、预计与实际成交日期、取消或退款状态。不要未经授权删除或覆盖原始记录；说明清洗和排除的影响。

建议的逻辑字段如下，按实际系统映射，不能据此声称某平台支持同名接口：

| 类别 | 字段 |
| --- | --- |
| 主体 | 商机 ID、客户 ID / 名称、负责人、业务类型、来源 |
| 金额 | 金额、币种、金额口径、经常性 / 一次性区分 |
| 状态 | 原始阶段、标准阶段、赢单 / 输单状态、输单原因 |
| 时间 | 创建日、资格确认日、阶段变更日、预计成交日、实际成交日、更新时间 |
| 证据 | 已确认痛点、关键人角色、最近客户互动、客户下一步、客户确认日期 |
| 预测 | 概率及来源、预测类别、预测区间、关键阻碍 |

写入前按实际字段类型准备变更集；区分新建、更新、关联不明和重复疑似记录。仅有客户名称时不能盲目覆盖同名客户。

## 2. ROI、TCO 与回收期

每项输入记录：数值、单位、期间、来源、采用率、兑现条件和可信程度。金额必须使用相同币种与期间；跨期现金流或税务影响有实质意义时另列限制。

**TCO（总拥有成本）**：在同一观察期内，汇总许可 / 订阅、一次性实施、迁移与集成、培训、运行维护和必要退出成本。分别算现状与新方案，写明内部人力是否纳入。

`TCO 差额 = 现状 TCO − 新方案 TCO`

TCO 差额回答成本变化，不能直接当作 ROI 百分比。比较成本节约时说明投入已包含在哪里，避免重复扣除。

**项目 ROI**：明确采用“相对现状的项目收益与新增投入”口径。

`期间收益 = 可兑现的现金成本节约 + 新增毛利 + 其他可验证现金收益`

`期间投入 = 一次性新增投入 + 期间新增持续投入`

`ROI = (期间收益 − 期间投入) ÷ 期间投入 × 100%`

- 收入增长先乘相应毛利率；不要把销售收入全当利润。增量成本若已在毛利中扣除，不再计入投入重复扣减。
- 以节约费用作收益时，不能又把同一笔节约作为负投入。若选用 TCO 差额作净收益，需要重新说明分子分母，不混用两套口径。
- 节省工时通常先代表产能释放；没有减少外包、加班、招聘或其他可兑现成本的证据时，不自动计入现金收益。
- 产能价值可单列估算：`人数 × 每人每月节约小时 × 小时成本 × 月数 × 采用率 × 实现系数`。各比例须解释，不能为得到好看的 ROI 调参。
- 分母为零或非正时，说明该口径不适用；缺少数据时不输出精确百分比。

**回收期**：优先用逐月累计净现金流找到首次非负的月份。若月度净流入恒定且为正，可用 `一次性投入 ÷（月度现金收益 − 月度新增持续成本）` 简化估算；明确收益爬坡、支付时间和取整规则。

**演示算例，全部为虚构输入**：假设收益已按实际采用条件调整，首年现金成本节约 12 万元，新增毛利 6 万元；一次性投入 3 万元，首年持续投入 5 万元。

- 首年收益 18 万元，投入 8 万元，净收益 10 万元，ROI 为 125%。
- 假设收益和持续成本按月均匀发生，一次性投入发生在期初，回收期约为 `3 ÷ ((18 − 5) / 12) = 2.77` 个月；按月末现金流检查则在第 3 个月末回收。
- 未考虑税费、资金时间价值和爬坡；不能把这一结果套用于真实客户。

真实方案至少说明保守与基准情景中的关键变动变量；用户需要时再加乐观情景。输出计算式、假设和验证方法，收益估算不作为保证。

## 3. 漏斗与趋势

阶段应由客户已完成的可观察动作定义，并映射公司实际流程。例如“已发方案”是卖方活动，“客户确认方案满足关键要求”才是可验证的购买进展。

| 指标 | 计算与解释 |
| --- | --- |
| 阶段转化率 A→B | 同一来源队列中进入 B 的商机数 ÷ 该队列进入 A 的商机数；固定观察期限，说明未成熟队列和缺失历史 |
| 赢单率 | 同期已决定的赢单数 ÷（赢单数 + 输单数）；明确日期以实际结案日为准，未结案另列 |
| 销售周期 | 同一口径的开始节点至实际成交日；说明样本，优先同时看中位数及分布 |
| 阶段停留时间 | 截止日减最近进入该阶段日期；没有阶段变更记录时无法准确计算 |
| 目标缺口 | 同口径目标减同口径已实现；签约、确认收入和回款分别计算 |
| 商机覆盖倍数 | 符合目标期间与金额口径的未加权在途金额 ÷ 目标缺口；缺口不大于零时标不适用 |

不能把当前各阶段存量的比值叫真实转化率。只有快照时可报告阶段分布、金额集中度、逾期和缺失情况；要分析阶段流转需补变更历史或定义可比较的新增队列。

趋势分析控制观察天数、季节性、渠道、客群、产品、人员和口径变化。样本小或有未成熟队列时标明限制；相关变化不能直接证明因果。

覆盖倍数和健康阈值应结合本团队历史、销售周期与目标期间设定，没有统一适用的“合格倍数”。

## 4. 预测与高意向识别

预测先确定“哪个期间、哪个业务范围、哪个金额指标”。在途概率必须对应**目标期间内成交的概率**；最终有可能赢单不等于本季度能赢单。

`加权在途预测 = Σ（期间内符合条件的商机金额 × 该商机期间内成交概率）`

`期间预计总额 = 同口径已实现额 + 加权在途预测`

- 优先使用已校准、适合当前客群和期间的历史概率或用户批准口径；若只有历史最终赢单率，要说明不能直接解释为期间内成交概率。
- 缺少可靠概率时，不把阶段名称机械映射为 20% / 50% / 80%。给出已实现额、可核查的在途分布及基于明确条件的情景金额，不伪装成统计预测。
- 历史阶段概率与决策链、预算、采购流程、实际承诺和最新互动相互核对。大额集中、反复延期、关键人缺位、采购未启动或久无客户动作应单独说明。
- 已赢单与在途不得重复计入；跨币种先约定汇率及日期。报价额、合同额和 ARR 不能直接相加。
- Commit 等预测类别是管理判断，必须说明本团队定义与证据，不能等同 100% 概率或客户保证。
- 事后用实际结果检查预测偏差和概率校准，识别系统性高估、低估与客群差异；数据不足时先累计可比较记录。

高意向判断同时看问题适配、可兑现价值、决策参与和真实行动。浏览、下载、情绪积极或单次问价不能单独确定购买意图。用“信号—来源与日期—支持什么判断—还缺什么—下一次验证”记录。

## 5. 外联、唤醒与客户经营

统一活动批次、去重客户、观察期限和触达渠道，分别记录尝试、成功提交、实际送达或接通、有效对话、合格机会与成交。工具显示发送成功不等于进入收件箱；状态不可验证时使用实际可知的名称。

| 指标 | 计算与限制 |
| --- | --- |
| 正向回复率 | 有明确相关兴趣或下一步意愿的去重客户数 ÷ 同批实际送达客户数；剔除自动回复、重复及拒绝，送达不可知时改用发送口径并明确说明 |
| 合格机会形成率 | 同队列中达到约定资格条件的去重客户数 ÷ 发生有效对话的去重客户数；保留资格定义 |
| 询盘首次有效响应时长 | 从询盘收到至第一次实质回应的间隔；统一时区，自动收件确认单列，报告样本与中位数 |
| 单个合格机会成本 | 同范围的工具、渠道、人工与相关资源成本 ÷ 新增合格机会数；分母为零时不输出有限成本值 |
| 唤醒回复 / 成交率 | 按同一唤醒队列分别算有效回复客户或实际复购客户 ÷ 实际送达客户；领券和回复不等于成交 |
| 激励与活动净贡献 | 可核验的增量毛利减活动、激励和执行成本；没有对照或可靠基线时，说明无法将所有复购归因于活动 |

对比序列或渠道时同时看机会质量、成本和客户反感或退订信号。打开率受技术和测量条件影响，只能辅助判断；不通过发送更多邮件或拨打更多电话掩盖低适配。

需要客户健康分时使用事先说明的归一化指标和加权方式，如 `总分 = Σ（指标标准分 × 权重）`。说明指标方向、权重和缺失值处理；只覆盖部分维度时报告覆盖率及暂定性质。风险分不能自动解释为流失概率。

## 6. 输出要求

先报告能支持决策的结论，再列影响最大的异常和动作。结果旁保留分子、分母、期间、来源或计算依据。仅在用户需要图表或文件时创建相应成品；不为简单问题强行生成仪表盘。
